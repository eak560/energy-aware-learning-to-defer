# LILYGO T-Deck: ESP32-S3 handheld with a keyboard and LoRa radio

- Product family: T-Deck / T-Deck Plus / T-Deck Pro / T-Deck Cypher (retailer variants)
- Example listing: https://store.rokland.com/products/lilygo-t-deck-cypher-complete-edition-w-4000-or-8000-mah-battery-gps-keyboard-touchscreen
- Other listings: https://www.digitec.ch/en/s1/product/lilygo-t-deck-plus-esp32-s3-single-board-computer-kits-59858045 · https://openelab.com/products/lilygo-t-deck-pro-esp32s3
- Runs **Meshtastic**, open-source firmware for off-grid text messaging over a LoRa mesh (no phone network or internet).

Specs vary by variant (battery 2,000–8,000 mAh, 868/915 MHz radio, LCD or e-paper). Confirm on LILYGO's own site before buying.

**Why it's here:** it answers "when does text arrive at a battery-powered ESP32?". People type messages directly into an ESP32-S3 running on battery, and every message sent over LoRa costs airtime and energy. That's the device class where on-chip text classification with selective offloading to a base station makes sense.
